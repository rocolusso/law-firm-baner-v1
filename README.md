# Clario hero banner

Адаптивный анимированный HTML-баннер для hero-блока сайта Clario. Next.js 16 (App Router, статический экспорт) и Remotion Player.
Видеофайла нет: анимация считается в браузере по кадрам и работает как обычная страница.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000, внизу переключатели стиля, языка и формата
npm run build      # статический HTML в папке out/
npm run lint && npm test
```

## Пять стилей

Выбираются кнопками в интерфейсе или параметром адреса `?style=`:

| id               | что происходит                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| `light-burst`    | вспышка света у верхушки башни, окна загораются, фото на миг становится точками (по умолчанию) |
| `spotlight`      | прожектор обходит здания в темноте, потом свет заливает кадр                                   |
| `glass`          | матовые стеклянные панели в духе Apple, текст на главной панели                                |
| `poster`         | золотой фон с растром, фото в наклонном окне, слова на цветных плашках                         |
| `dots-to-scales` | фото рассыпается на точки, точки собираются в весы Clario                                      |

## Язык

Украинский по умолчанию, русский переключается кнопкой или `?lang=ru`. Тексты лежат в `src/banner/i18n/copy.ts`.

## Как встроить

Готовый баннер лежит в `out/embed/index.html`. Он занимает весь размер окна, поэтому формат задаёт iframe:

```html
<iframe
  src="https://your-domain/embed/?style=light-burst&lang=uk"
  style="width:100%;aspect-ratio:16/10;border:0"
  title="CLARIO"
  loading="lazy"
></iframe>
```

Или подключите компонент `CityBanner` из `src/banner/ui/CityBanner.tsx` в своём Next.js-проекте и задайте родителю размер.
Целевые размеры hero сайта: 16:10 на десктопе (1280×800) и около 7:10 на мобильном (449×642).

## Что менять

- `src/banner/banner.config.ts`: ссылка кнопки `CTA_HREF` (сейчас `#consultation`), размеры кнопки, флаг `backdropFilter`, `LITE_CANVAS_SCALE`.
- `src/banner/theme.ts`: палитра ролями. По умолчанию `luxury` (синий и золото), есть чёрно-белая `mono`. Смена палитры не требует правок сцен.
- `src/banner/styles/`: по файлу на стиль, список в `registry.ts`. Тайминги заданы в кадрах (30 fps) в начале каждого файла.
- `src/banner/kit/`: общие части: фото и огни, скан, текст и кнопка, знак Clario.
- `public/banner/`: слои фото. `src/banner/image-data.json` с огнями окон и сеткой полутонов построен по этому снимку, для другого фото его надо пересобрать.

## Логотип

Знак и слово Clario берутся из векторного EPS. Чтобы пересобрать контуры после замены файла:

```bash
node scripts/eps-to-svg.mjs path/to/Clario.eps
```

Скрипт пишет `src/banner/brand/clario-mark.ts` и `public/brand/clario.svg`.

## Шрифт

Inter (variable) лежит в `public/fonts/`, лицензия SIL OFL рядом. Подключён через `@font-face` в `src/app/globals.css`, как на сайте.
Шрифт не предзагружается в `<head>`: он нужен только анимации, и `CityBanner` подгружает его сам перед стартом, чтобы он не отнимал канал у постера.

## Картинки

Исходники лежат в `assets/source/` и на сайт не попадают. Готовые файлы в `public/banner/` собирает скрипт:

```bash
npm i --no-save sharp playwright
node scripts/build-images.mjs
```

Он делает постер в AVIF и WebP трёх размеров, слои неба и зданий в WebP и слитую сцену для лёгкого режима.
Сцена собирается в Chromium теми же CSS-фильтрами, что в `src/banner/kit/photo.tsx`, отдельно для каждой темы. Если меняете фильтры или цвет `navy` в теме, поправьте константы в начале скрипта и запустите его заново.

## Как работает адаптив

`CityBanner` измеряет свой блок и передаёт в Player логический размер с тем же соотношением сторон, а также `px`: сколько пикселей композиции приходится на CSS-пиксель.
`getLayout()` в `src/banner/geometry.ts` по соотношению сторон выбирает раскладку текста (горизонтальную или вертикальную), кнопка всегда 48 CSS px высотой, как на сайте.
`coverRect()` держит башню в кадре при любом формате. Анимация ставится на паузу вне экрана и в скрытой вкладке.
При `prefers-reduced-motion` показывается спокойный статичный кадр стиля.

## Скорость и мобильные

Сначала в HTML приходит постер (`<img fetchpriority="high">`), он и есть LCP. Remotion Player и код выбранного стиля грузятся отдельным куском после события `load`, в простое браузера и только когда баннер на экране. Фотослои рисуются на canvas, поэтому не перехватывают LCP у постера.

Качество бывает трёх уровней (`src/banner/geometry.ts`):

- `high`: полный набор эффектов, композиция до 2,2 млн пикселей. Обычный компьютер.
- `low`: до 1,2 млн пикселей, одна слитая картинка вместо трёх слоёв с фильтрами, без `backdrop-filter`, `mix-blend-mode` и размытия на весь кадр, холсты в 0,75 разрешения. Телефоны, планшеты, слабые машины.
- `min`: то же, до 0,7 млн пикселей. `Save-Data` или автопонижение.

Начальный уровень выбирает `src/banner/ui/quality.ts`. Если анимация две секунды подряд идёт медленнее 22 кадров в секунду, уровень понижается сам, а ниже `min` баннер замирает на статичном кадре.
Изменения размера (панель адреса на телефоне) применяются с паузой 250 мс, поэтому холсты не пересоздаются на каждый пиксель.

Для проверки на телефоне есть два параметра `/embed`: `?perf=1` показывает в углу fps, уровень и размер композиции, `?tier=low` (или `high`, `min`) фиксирует уровень и выключает автопонижение.

Кэширование файлов на Vercel задаёт `vercel.json`.

## Доступность

Настоящий заголовок и ссылка лежат поверх холста (`h2.sr-only` и `a.banner-cta`), поэтому читаются скринридерами и ходят по Tab.
Вспышки не чаще трёх в секунду.
